# 복합 어종 옵션 · 다중 티어 · 검색 패널 개선 (2026.10.26.5)

## 확인한 원인과 수정 기준

기존 선택창은 원본 조합 키를 `split('+')`로 개별 어종에 펼쳐서 옵션을 만들었다. 일정에는 `주꾸미+갑오징어`가 보존되어 있었지만 선택창에는 그 조합을 직접 고를 항목이 없었다. 앞선 릴리스의 정확한 집합 일치 필터는 유지하면서 **선택 옵션 자체를 단독·복합으로 구분**했다.

- `주꾸미`, `갑오징어`, `주꾸미+갑오징어`를 별개 옵션으로 제공한다. `광어+우럭` 등 다른 조합도 같은 방식으로 처리한다.
- 쉼표·공백·어순·쭈꾸미/주꾸미 별칭은 정규화하고 동일 조합은 중복 생성하지 않는다.
- 옵션 여러 개를 고르면 **각 옵션과 정확히 일치하는 일정들의 합집합**을 표시한다. 주꾸미 단독과 갑오징어 단독을 함께 골라도 복합 출조가 자동 포함되지 않는다. 복합 출조는 복합 옵션을 명시적으로 선택한다.
- 원본 출조명, 전체 어종, 플랫폼별 선박 ID, 잔여석과 예약 링크는 그대로 보존한다. 어종 필터 변경만으로 API를 다시 호출하지 않는다.
- 과거 백업의 `['주꾸미','갑오징어']`는 과거 의미대로 한 복합 조합으로 해석한다. 새 UI 선택값은 `{mode:'options',keys:[...]}`에 저장해 이전 배열과 구분한다. 백업 왕복과 재조회 후에도 의미가 바뀌지 않는다.
- 복합 일정만 있는 경우에도 구성 어종의 단독 옵션을 제공하며 실제 단독 일정이 없으면 `단독 0건`으로 표시한다. 미확인 원문을 단독 어종으로 추정하지 않는다.

## UI 및 상태 관리

- 지역·검색조건·어종 패널은 캘린더 위에 둔다. 패널마다 `닫기 ×`가 있으며 선택값은 유지한다.
- `선택선박 · 선박 선택` 버튼을 캘린더/날짜별 결과 아래로 이동했다. 선박 선택·관리 영역도 아래에 유지했다.
- 지역을 기본 4열, 760px 이하 2열의 접이식 체크박스로 구성했다. 목록 내부 스크롤, 항목별 전체/초기화, 다중 선택, 유효한 하위 지역 유지 기능을 제공한다. Ctrl 키가 필요하지 않다.
- 지역 선택창은 선박 정보나 지역 값이 바뀔 때만 다시 만든다. 월 이동·물때 갱신 때문에 체크박스·스크롤·키보드 초점이 불필요하게 재생성되지 않는다.
- 1·2·3·기타 티어를 각각 토글할 수 있고 전체/해제 버튼을 제공한다. 조회 대상, 결과, 날짜별 실패 안내에 같은 다중 티어 조건을 적용한다. 조회 필터 변경으로 선박에 지정된 티어를 바꾸지 않는다.
- 실제 조회와 저장이 성공한 뒤 결과 표시를 마치면 패널을 닫는다. 성공했지만 조건에 맞는 결과가 없는 경우도 접고 선택값을 유지한다. 요청 시작·취소에서는 자동으로 닫지 않는다. 전체/일부 실패 시 검색조건 패널을 열어 재시도할 수 있게 한다.
- 정상 완료 후 닫힌 패널 안에 키보드 초점이 남지 않도록 조회 버튼으로 이동한다. 조회 버튼이 활성화된 뒤 처리한다.
- 필터 초기화는 지역·티어 선택 조건·어종·검색어를 초기화한다. 개인 선박 목록과 지정 티어, 선택한 선박은 유지한다.

## 실제 응답 검증
