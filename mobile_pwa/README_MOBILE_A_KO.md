# 모바일 월별 예약 조회

주소: https://plabene.github.io/the-fishing/

1. 내 선박 관리에서 선박을 선택하고 월·인원을 정합니다.
2. **조회 API 사용 → 실시간 월 조회**를 누릅니다. 2026-10-22 현재 API는 본인 계정 재배포 대기 상태입니다. 배포 완료 후 새 API를 연결해야 합니다.
3. 달력·월 전체 목록에서 상품·잔여석·조회 시각을 확인합니다. 선박별 조회 결과에서 실패 단계와 공식 링크를 확인할 수 있습니다.
4. 다른 API를 쓰려면 **조회 API 연결**에서 배포 주소를 입력하고 연결 확인 및 저장을 누릅니다. 계정 비밀번호나 토큰을 입력하지 않습니다.
5. 저장 자료만 보려면 **저장 자료 검색**을 선택합니다. PC 조회 자료 가져오기·JSON 백업도 사용할 수 있습니다.

PC 선박 목록 512척과 선택 83척·티어를 유지합니다. 자료·선박 설정은 기기별이며 자동 동기화하지 않습니다. 성공한 선박만 해당 월 자료를 바꾸고, 실패하거나 조회하지 않은 선박은 이전 자료를 보존합니다. 10분 이내 서버 캐시는 관측 시각을 유지한 채 재사용합니다.

이전 임시 API는 만료 후 접속되지 않아 기본 연결에서 제거했습니다. 기존 임시 주소를 저장한 기기도 새 기본 주소로 전환할 수 있게 처리했습니다. 본인 Cloudflare 계정에 배포해야 계속 사용할 수 있습니다. 자세한 절차는 [조회 API 안내](availability_api/README_KO.md)를 참고하세요.

Android Chrome 또는 iOS Safari의 홈 화면 추가/설치 기능으로 사용할 수 있습니다. 이전 화면이면 앱을 닫았다가 다시 열고 새로고침하세요. 실제 단말 설치 메뉴는 직접 검증하지 않았습니다. 브라우저 저장소를 지우면 기기 자료가 삭제되므로 필요한 자료를 먼저 백업하세요.
