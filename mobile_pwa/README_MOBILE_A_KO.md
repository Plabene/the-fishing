# 모바일 월별 예약 조회

선상24 선박 검색·플랫폼 필터·공통 지역 분류를 추가했습니다. 선상24 실시간 조회는 허가 전까지 비활성 상태이며 공식 페이지에서 확인합니다. [통합 기능과 검증 기록](INTEGRATION_SUNSANG24_KO.md)을 참고하세요.

선상24 조회가 비어 있는 원인과 공식 제휴 문의·API 연결 절차는 [선상24 API 연동 진단과 신청](availability_api/README_KO.md#선상24-api-연동-진단과-신청)에 정리했습니다. 월별 캘린더의 날짜 칸에서는 예약사이트 태그를 제거하고 선박명을 먼저 줄바꿈해 표시합니다. 플랫폼 태그는 선박 관리와 상세 결과에서 확인할 수 있습니다.

주소: https://plabene.github.io/the-fishing/

**내 선박 관리 → 내 티어 목록 보관**에서 **티어 목록 저장**을 누르면 날짜가 붙은 JSON 파일을 다운로드합니다. 휴대폰의 다운로드·파일 앱에서 파일을 확인하세요. 파일 공유가 가능한 기기에는 **티어 파일 공유**도 표시되며, 공유 화면에서 원하는 저장 위치를 선택할 수 있습니다. 다른 기기에서는 **티어 파일 불러오기**로 복원합니다. 파일에 포함된 선박의 티어·순서·선택 상태만 적용하고, 나머지 선박과 조회 기록은 유지합니다. 복원 직후 **변경 되돌리기**를 사용할 수 있습니다. 조회 자료까지 보관하려면 기존 **저장된 월별 자료 · 가져오기 · 백업 → 백업 저장**을 사용하세요.

선상24 PC의 티어 선박 **21척(1티어 7, 2티어 4, 기타 10)**을 추가로 승계합니다. 업데이트 후 처음 열 때 아직 티어를 지정하지 않은 항목에 적용하며, 웹에서 이미 지정한 티어와 삭제한 선박은 보존합니다. PC 기준으로 다시 맞추려면 **선상24 PC 티어 가져오기 → 선상24 PC 티어 다시 적용**을 누르세요. 이 작업은 PC 목록의 21척에만 적용됩니다. 이후 PC에서 바꾸는 설정은 자동 동기화되지 않습니다.

내 선박 관리의 200척 표시 제한을 없앴습니다. 현재 기본 목록 **1,057척**을 모두 표시하며, 플랫폼·지역·검색어를 지정하면 일치하는 선박을 개수 제한 없이 표시합니다. 개인적으로 삭제한 선박은 자동으로 복원하지 않습니다.

1. 내 선박 관리에서 선박을 선택하고 월·인원을 정합니다.
2. **조회 API 사용 → 실시간 월 조회**를 누릅니다. 본인 Cloudflare 계정에 배포한 API가 기본 연결되어 있습니다.
3. 달력·월 전체 목록에서 상품·잔여석·조회 시각을 확인합니다. 선박별 조회 결과에서 실패 단계와 공식 링크를 확인할 수 있습니다.
4. 다른 API를 쓰려면 **조회 API 연결**에서 배포 주소를 입력하고 연결 확인 및 저장을 누릅니다. 계정 비밀번호나 토큰을 입력하지 않습니다.
5. 저장 자료만 보려면 **이전 자료 열람 (예약 판단용 아님)**을 선택합니다. PC 조회 자료 가져오기·JSON 백업도 사용할 수 있습니다.

**지역·어종·선박 필터**에서 권역·시도/지역·세부 지역·출항지를 선택하면 해당 지역의 선택 선박만 새로 조회합니다. **전체 지역**으로 해제합니다. 같은 지역 조건이 내 선박 관리에도 적용됩니다. PC·더피싱 사이트의 지역 분류를 사용하며 지역 불명은 **미확인**으로 표시합니다.

**어종 선택**에서 원하는 어종을 여러 개 체크하면 달력·날짜 상세·월 전체 목록에 즉시 적용됩니다. 예를 들어 **갑오징어 + 문어**를 체크하면 두 어종 중 하나라도 포함된 출조를 표시합니다. 복합 출조가 여러 선택에 걸려도 중복 표시하지 않습니다. **전체 어종**으로 전체 표시를 복구하고, **선택 해제**는 모두 해제하여 결과를 0개로 만듭니다. 전체 어종 상태에서 체크를 시작하면 체크한 어종만 표시합니다.

**어종 포함·제외**에서는 기존처럼 출조별 어종 조합을 제외할 수 있습니다. 체크 선택을 바꾸거나 **전체 어종**을 누르면 기존 제외 조건이 초기화됩니다. 쭈꾸미·갑오징어 복합 출조는 쭈꾸미 또는 갑오징어를 선택해도 표시됩니다. 어종 선택은 월 변경·앱 재실행 후에도 유지되고 백업에 포함됩니다. 기존 단일 선택 백업도 자동으로 이어받습니다. 필터 변경에는 추가 API 요청이 없습니다.

원본 출조명은 보존하며 `쭈/갑`, `쭈.갑오징어`, `쭈꾸미&갑이` 등 실제 출조명 표기를 정규화합니다. `다운샷`·`외수질`처럼 어종 없는 낚시 방법은 **기타/미확인**으로 표시합니다. 기존 저장 자료도 출조명을 기준으로 다시 분류하되 관측 시각이나 잔여석을 갱신한 것으로 처리하지 않습니다.

조회 버튼을 누를 때마다 원본 월 달력에서 잔여석을 새로 확인합니다. 이전 좌석은 현재 결과에서 제외하고 이번 조회에 성공한 선박만 표시합니다. 버튼 아래 상태바에 경과 시간·완료/전체 수·성공/실패 수가 표시됩니다.

PC에서 승계한 목록에 공개 목록 갱신을 누적합니다. 기본 목록은 매주 월요일 06:17 한국시간에 GitHub Actions로 확인·배포하고, 앱에서 새 버전을 열 때 개인 목록에 반영합니다. 신규 선박은 선택 해제 상태로 추가되며 개인 티어·선택·직접 수정한 내용·삭제한 선박은 유지됩니다. 개인 설정은 기기별로 저장되며 GitHub나 다른 기기로 업로드하지 않습니다. 실패한 선박의 이전 좌석은 백업에 남아도 현재 조회 결과에 섞이지 않습니다.

2026-10-22 본인 계정 API `https://thefishing-availability.thefishing-mobile-a.workers.dev`를 배포하고 연결했습니다. 기존 임시 주소를 저장한 기기도 새 기본 주소로 전환합니다. 과거에 직접 API 연결을 해제한 기기는 **조회 API 연결**에서 위 주소를 입력하고 연결 확인 및 저장을 누르세요. 자세한 절차는 [조회 API 안내](availability_api/README_KO.md)를 참고하세요.

Android Chrome 또는 iOS Safari의 홈 화면 추가/설치 기능으로 사용할 수 있습니다. 이전 화면이면 앱을 닫았다가 다시 열고 새로고침하세요. 실제 단말 설치 메뉴는 직접 검증하지 않았습니다. 브라우저 저장소를 지우면 기기 자료가 삭제되므로 필요한 자료를 먼저 백업하세요.
