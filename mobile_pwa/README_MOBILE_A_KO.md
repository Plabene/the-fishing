# 월별 예약 조회 — 서버 없는 모바일 웹

현재 배포 주소: https://plabene.github.io/the-fishing/

조회 월과 인원을 정하고 **브라우저 직접 조회 → 실시간 월 조회**를 누릅니다. 이 기기가 더피싱의 상세 페이지와 월 달력을 직접 요청합니다. PC가 켜져 있거나 Python 수집 서버가 실행될 필요는 없습니다. PC에서 발생한 404가 모바일 조회를 자동으로 차단하지 않습니다.

## 사용 방법

1. 내 선박 관리에서 조회할 선박을 선택하고 티어를 정합니다. PC 목록 512척과 선택 83척이 기본 포함됩니다.
2. 월·인원·티어를 선택하고 직접 조회를 실행합니다. 진행 상황과 **선박별 조회 결과**에서 성공·HTTP 오류·미지원 등을 확인합니다. 언제든 조회 취소를 누를 수 있습니다.
3. 달력 또는 월 전체 목록에서 날짜별 출조 상품·잔여석·조회 시각을 확인합니다. 직접 조회에 성공한 선박만 해당 월의 결과를 교체합니다. 실패 또는 미조회 선박의 이전 자료는 보존합니다.
4. 인터넷을 사용할 수 없거나 이전 자료만 보고 싶으면 **저장 자료 검색**을 선택합니다. 초기 자료는 2026-10-01에 수집된 2026-10 일정이며 현재 좌석을 보장하지 않습니다.
5. 외부 사이트·운영사 페이지 선박은 직접 조회 미지원입니다. 공식 페이지 링크를 이용합니다.
6. **PC 조회 결과 가져오기 · 백업**에서 PC 월별 캐시나 백업을 가져오고 JSON 백업을 저장할 수 있습니다. 자료와 설정은 기기별이며 자동 동기화하지 않습니다.

## 직접 조회 범위

더피싱 숫자 UID 상세 GET → 검증된 월 달력 POST만 사용합니다. 예약 폼, 신청자, 로그인, 결제 요청은 하지 않습니다. 쿠키·자격 증명 전송이나 프록시는 사용하지 않습니다. 요청은 한 번에 하나, 최소 1초 간격이며 각 요청은 15초 제한입니다. 같은 탭의 10분 이내 성공 결과는 재사용합니다. 접근 제한·보안 화면에서 중단하고 자동 재시도하지 않습니다. 404는 접근 차단으로 단정하지 않습니다.

모바일 브라우저에서 공식 사이트가 열려도 웹앱이 다른 출처의 본문을 읽으려면 사이트의 CORS 허용이 필요합니다. 실패하면 **선박별 조회 결과**에 원인을 표시합니다. 네트워크/CORS/리디렉션을 구분할 수 없는 경우 그대로 미확인으로 안내합니다. 실제 모바일 운영 응답은 아직 검증하지 않았습니다. 소스와 UI는 모의 응답으로 테스트했습니다.

## 설치와 보관

Android Chrome 또는 iOS Safari에서 위 HTTPS 주소를 열고 브라우저의 홈 화면 추가/설치 기능을 사용할 수 있습니다. 정적 앱 화면만 서비스 워커에 저장하며 외부 HTML은 서비스 워커에 저장하지 않습니다. 읽어 온 공개 일정은 기기 IndexedDB에 저장합니다. 다시 열거나 백업으로 가져온 결과는 이전 자료로 구분합니다. 브라우저 저장소를 지우면 기기 자료가 삭제되므로 필요한 백업을 보관하세요.
