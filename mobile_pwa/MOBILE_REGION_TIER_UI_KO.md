# 지역·티어 중심 모바일 조회 화면 (2026.10.27.1)

검색 흐름을 **지역 선택 → 티어 선택 → 조회하기 → 날짜별 잔여석 확인**으로 정리했다. 기존 선박·티어 원본 JSON, IndexedDB 저장 형식, 사용자 보호 이력, 조회 API 및 예약 파싱은 변경하지 않았다.

## 원인과 변경

- 모바일 지역 요약에 최대 너비 48px와 말줄임이 적용되어 선택한 지역명이 잘렸다. 상단 지역 버튼에 전체 선택 지역명을 줄바꿈해서 표시하고, 선택 상태에 체크·진한 테두리·배경색을 적용했다. 상단 티어 요약과 복수 선택 버튼도 저장된 조건에 맞춰 갱신된다.
- 별도 검색조건 패널, 예약 결과의 선박명 검색, 선택선박 바로가기, 선박 체크박스, 표시된 선박 일괄 선택·해제 및 선택 선박만 보기 UI를 제거했다.
- 조회 대상은 명시적으로 등록된 티어와 지역·플랫폼 조건으로 결정한다. 과거 `selectedUids` 체크가 해제돼 있어도 등록된 티어에 속하면 조회 대상에 포함된다. 티어가 없는 선박은 포함하지 않는다. `selectedUids` 자체는 지우거나 덮어쓰지 않고 기존 백업 호환성을 유지한다.
- 마지막 제공 백업 기준 티어 235척(1티어 16, 2티어 21, 3티어 31, 기타 167)이 전체 티어 조회 대상이다. 과거 선택 126척은 백업 데이터에 보존된다. 사용자가 변경한 개인 티어는 해당 기기의 설정을 계속 사용한다.
- 달력 아래 접힌 **티어 선박 관리**에서 선박 찾기, 티어 등록·변경, 상세 정보 및 백업을 유지했다. 이 관리용 검색은 잔여석 조회 조건이 아니다. 공식 예약 링크 확인도 별도 접힌 영역에 남겼다.
- 지역 옵션·티어·주요 조회 버튼의 조작 높이는 44px다. 열린 지역 패널은 전체 너비를 사용하며 내부 목록만 스크롤한다. 좁은 화면의 ‘지역’ 제목은 한 줄로 유지한다. 데스크톱 조회 컨트롤은 최대 너비를 제한했다.
- 성공 또는 정상 빈 결과 후 지역·어종 패널을 접고, 오류·부분 실패 시 지역 조건을 확인할 수 있게 유지한다. 조건 변경만으로 API를 추가 호출하지 않으며 조회하기는 기존처럼 새 원본 조회를 요청한다.

## 검증

- 로컬 자동 테스트 **58파일 338개 통과**. 백업의 모든 티어 포함, 미등록 제외, 과거 체크 상태 보존, 지역·복수 티어 조합, 새 요청의 `fresh=1`, 월 변경, 복합 어종, 부분 실패·취소, 패널 접기, 티어 관리, 가져오기·복원 등을 확인했다.
- TypeScript/프로덕션 빌드, 번들 검사, API dry-run 통과. 마지막 제목 줄바꿈 보완까지 GitHub Actions의 테스트·빌드·배포가 모두 통과했다.
- 실제 로컬 브라우저에서 360·375·390·430·768·1280px로 열린/닫힌 지역 패널을 점검했다. 측정한 주요 컨트롤의 가로 넘침은 0개였으며 최소 높이는 44px였다. 군산·부안 다중 선택, 1·2티어 동시 선택, 요약 갱신과 월 변경도 확인했다. 물리적 휴대폰에서 실행한 검사는 아니다.
- 로컬 `127.0.0.1:5180`의 실제 API 요청은 연결 실패로 표시됐고, 이전 잔여석을 성공 결과로 표시하지 않았다. 운영 API의 허용 출처 설정은 `https://plabene.github.io` 하나이며 이번에 변경하지 않았다.
- 운영 API를 운영 출처 헤더와 `fresh=1`로 직접 점검했다. 2026년 11월 표본에서 더피싱 UID 1441은 HTTP 200 / `ALLOWED_READABLE` / 85개 일정, 선상24 ship 2021의 공개 예약표는 HTTP 200 / `ALLOWED_READABLE` / 180개 일정 응답이었다. 후자의 180개는 공개 예약표 전체 응답 수로, 한 척의 고유 일정 수로 집계하지 않았다. 두 응답 모두 `fresh=true`, `cached=false`, 운영 출처 CORS 헤더가 확인됐다. 전국 모든 선박의 실시간 조회를 검증했다는 의미는 아니다.
- 마지막 운영 브라우저 이동 시 도구가 ‘Local browser use is disabled in Work settings’를 반환했다. 따라서 **배포 후 운영 화면의 클릭부터 결과 표시까지는 브라우저로 검증하지 못했다.** 로컬 브라우저 조작, 운영 API 직접 응답, 배포 자산 검증은 각각 구분한다.
